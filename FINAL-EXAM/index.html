Question 1: Grade Calculator (IF/ELSE)

Write a function that takes a score (0-100) and returns the letter grade:

  • 90-100: 'A'
  • 80-89: 'B'
  • 70-79: 'C'
  • 60-69: 'D'
  • Below 60: 'F'

Question 2: Day Name (SWITCH CASE)

1=Monday, 2=Tuesday, 3=Wednesday, 4=Thursday, 5=Friday, 6=Saturday, 7=Sunday

Question 3: Filter Adults (ARRAY FILTER)

Test Array: [12, 18, 25, 15, 30, 16, 21]

Question 4: Double Numbers (ARRAY MAP)

Question 5: Reverse String (STRING METHODS)

Question 6: Calculator Function (FUNCTIONS)

Test Array: [10, 20, 30, 40, 50]

MUST use .find() method
